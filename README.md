
# 🛡️ Telegram 私聊转发与主动防御机器人 (V32.2)

> **版本**: V32.2 Security Edition
> **语言**: Python 3
> **依赖**: pyTelegramBotAPI, requests

这是一个面向需要高级安全管理功能的 Telegram 私聊转发机器人。除了双向转发外，它集成了**数学验证码、管理员封禁控制、多重反垃圾邮件**机制，旨在最大程度减少管理员接收到的无效和恶意消息。

![License](https://img.shields.io/badge/License-MIT-green)

## ✨ 核心功能亮点

*   **🔐 数学验证码 (CAPTCHA)**：
    *   所有首次私聊的**新用户**必须在 60 秒内完成一个简单的数学算术题。
    *   验证成功后，用户进入正常流程；验证失败或超时，消息将被丢弃。
*   **🔨 管理员控制**：
    *   管理员可以通过**回复**被转发的用户消息，使用 `/ban`、`/unban`、`/check` 命令，对用户进行精准的禁用管理。
*   **📨 双向消息转发**：
    *   **用户 -> 管理员**：转发各类消息类型，包括文本、媒体、贴纸、GIF 等。
    *   **管理员 -> 用户**：管理员**回复**转发消息即可快速回复用户。
*   **🛡️ 智能防骚扰 (Anti-Spam)**：
    *   **多源关键词过滤**：支持内置、自定义本地关键词及远程 URL 实时同步（每小时更新）。
    *   **违规提醒**：当消息被关键词拦截或洪泛拦截时，会向用户发送清晰的通知。
*   **🌊 防刷屏控制 (Anti-Flood)**：
    *   限制用户在短时间内（默认 10秒）的发送频率（默认 5 条），超出频率将进入惩罚期。

## 🛠️ 部署指南

### 1. 准备工作

*   一个 Telegram Bot Token (通过 [@BotFather](https://t.me/BotFather) 获取)。
*   你的 Telegram User ID (作为管理员，通过 [@userinfobot](https://t.me/userinfobot) 获取)。
*   Python 3.6 或以上环境。

### 2. 安装依赖

```bash
pip install pyTelegramBotAPI requests
````

### 3\. 环境变量配置 (Environment Variables)

| 变量名 | 必填 | 默认值 | 说明 |
| :--- | :---: | :--- | :--- |
| **`BOT_TOKEN`** | ✅ | 无 | 你的 Telegram 机器人 Token |
| **`ADMIN_ID`** | ✅ | 无 | 管理员的数字 ID (例如 `123456789`) |
| `REMOTE_SPAM_URL` | ❌ | (内置 GitHub URL) | 自定义远程垃圾词库的 URL (Raw Text 格式) |
| `CUSTOM_SPAM_KEYWORDS` | ❌ | 无 | 额外的自定义拦截词，用英文逗号 `,` 分隔 |

### 4\. 运行机器人

```bash
# 设置环境变量 (Linux/Mac 示例)
export BOT_TOKEN="你的_TOKEN"
export ADMIN_ID="你的_ID"

# 启动脚本
python bot.py
```

## 📝 使用说明 (管理员)

### 1\. 消息转发与回复

管理员收到的转发消息会附加用户信息。直接**回复 (Reply)** 该转发消息，内容将原封不动地发送给用户。

### 2\. 管理员封禁命令

所有管理命令都必须通过**回复**一条被转发的用户消息来执行。

| 命令 | 述描 | 用法示例 | 默认/说明 |
| :--- | :--- | :--- | :--- |
| **`/ban`** | 禁用目标用户，阻止其发送消息。 | `/ban` | 默认禁用 **1800 秒** (30 分钟)。 |
| **`/ban <秒数>`** | 禁用目标用户指定的秒数。 | `/ban 3600` | 禁用 1 小时。 |
| **`/unban`** | 解除对目标用户的禁用状态。 | `/unban` | 立即解除。 |
| **`/check`** | 检查目标用户当前是否处于禁用状态。 | `/check` | 仅供查询。 |

> ⚠️ **特别提醒：** 务必对**机器人转发给您的消息**使用 "**回复**" 功能发送命令。

### 3\. 用户流程 (验证码)

用户首次私聊 Bot 时，需要：

  * 收到一条包含数学算式的消息（如：`请计算 5 + 3 = ?`）。
  * 在 **60 秒**内回复正确的答案（如：`8`）。
  * 验证成功后，即可开始正常发送消息。

## ⚙️ 附加说明

  * **消息 ID 映射**：Bot 使用一个容量限制的 FIFO (先进先出) 字典来维护管理员消息 ID 和原始用户 ID 的映射关系，最大容量为 1000 条，以防止内存无限增长。
  * **关键词更新**：系统启动后台线程，每隔 **1 小时**（3600 秒）会自动尝试从 `REMOTE_SPAM_URL` 抓取最新的关键词列表。
