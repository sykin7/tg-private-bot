
# Telegram 全能群管 & 客服机器人 🤖

这是一个基于 Python 的轻量级 Telegram 机器人，集成了**群组管理**、**入群验证**、**广告拦截**、**私聊客服**以及**自动清理**功能。

专为容器化部署（Docker/Zeabur/Leaflow/VPS）设计，通过环境变量配置，无需修改代码即可使用。

## ✨ 主要功能

  * **🛡️ 智能群管**：
      * **入群验证**：新成员进群必须回答简单的数学题（如 1+1=2），60秒内未回答或回答错误将被踢出。
      * **广告拦截**：自动检测违禁词（如兼职、USDT等），秒删消息并封禁发送者。
      * **防刷屏**：检测短时间内大量发送消息的用户并进行限制。
  * **💬 客服系统**：
      * **私聊转发**：用户私聊机器人的消息会直接转发给管理员（Admin）。
      * **双向回复**：管理员回复转发的消息，机器人会自动把回复发给用户。
  * **📢 广播功能**：管理员可以使用命令一键向所有历史交互过的用户发送广播消息。
  * **🧹 自动维护**：
      * **自动回复**：支持关键词自动回复（需在代码中定义或后续扩展）。
      * **空间保护**：数据库自动清理，只保留最近 7 天或最新的 1000 条记录，防止内存溢出。

## ⚙️ 部署配置 (环境变量)

本项目推荐使用 Docker 或云平台部署。**不需要修改代码**，只需在部署时填写以下 **Environment Variables (环境变量)**：

### 必填变量 (Required)

| 变量名 (Key) | 说明 | 示例值 |
| :--- | :--- | :--- |
| `TOKEN` | **[必须]** 机器人的 API Token (找 @BotFather 获取) | `761234:AAHg...` |
| `ADMIN_ID` | **[必须]** 管理员的 Telegram 数字 ID (找 @userinfobot 获取) | `123456789` |
| `WEBHOOK_URL` | **[必须]** 你的 HTTPS 域名 (末尾不要带 `/`) | `https://bot.yourdomain.com` |

### 选填变量 (Optional)

| 变量名 (Key) | 默认值 | 说明 |
| :--- | :--- | :--- |
| `PORT` | `8080` | 程序监听端口，需与容器对外端口一致 |
| `SPAM_KEYWORDS` | (见说明) | 违禁词列表，使用**英文逗号**分隔 |
| `RATE_LIMIT_WINDOW`| `60` | 防刷屏检测时间窗口 (秒) |
| `RATE_LIMIT_COUNT` | `10` | 上述时间内允许发送的最大消息数 |
| `BAN_DURATION` | `3600` | 违规/验证失败的封禁时长 (秒) |
| `LOG_RETENTION` | `7` | 数据保留天数 |

> **关于 `SPAM_KEYWORDS` 的设置示例：**
> 如果你想拦截 "兼职"、"博彩" 和 "USDT"，请在环境变量中填写：
> `兼职,博彩,USDT`

## 🚀 部署方法

### Docker 部署 (推荐)

1.  **构建镜像**：

    ```bash
    docker build -t my-tg-bot .
    ```

2.  **运行容器**：

    ```bash
    docker run -d \
      --name telegram-bot \
      -p 8080:8080 \
      -e TOKEN="你的Token" \
      -e ADMIN_ID="你的ID" \
      -e WEBHOOK_URL="https://你的域名.com" \
      -e SPAM_KEYWORDS="兼职,刷单,USDT" \
      my-tg-bot
    ```

## 📖 使用说明 (操作指南)

### 1\. 管理员指令

只有在环境变量 `ADMIN_ID` 中设置的用户才能使用以下命令：

  * **`/gb <内容>` (全员广播)**

      * **作用**：向数据库中记录的所有用户发送消息。
      * **用法**：
        ```text
        /gb 大家好，这是今天的系统通知！
        ```
      * **注意**：不要滥用，以免被用户屏蔽。

  * **`/start`**

      * **作用**：测试机器人是否存活，并查看当前运行状态。

### 2\. 私聊模式 (客服功能)

  * **用户 -\> 机器人**：
      * 任何普通用户私聊机器人发送消息，机器人会**原样转发**给管理员 (`ADMIN_ID`)。
      * 管理员会看到消息来源是该用户的名字。
  * **管理员 -\> 用户**：
      * 管理员在 Telegram 中，对那条**转发过来的消息**点击 **"回复" (Reply)** 并输入内容。
      * 机器人会将你的回复内容发送给该用户。
      * *提示：无需输入特定指令，直接使用 Telegram 自带的回复功能即可。*

### 3\. 群组模式

  * **入群验证**：
      * 将机器人拉入群组，并赋予**管理员权限**（必须有删除消息和封禁用户的权限）。
      * 新用户进群后，机器人会自动发送一道数学题。
      * 用户需在 60 秒内点击正确答案，否则会被踢出。
  * **违禁词监控**：
      * 机器人会实时监控群消息。
      * 一旦出现 `SPAM_KEYWORDS` 中的词汇，消息会被立即删除，发送者会被禁言/封禁。

## 📂 数据清理机制

为了适应小内存 VPS 或免费容器：

1.  **启动时检查**：每次重启或每天特定时间（根据脚本逻辑），会自动清理超过 `LOG_RETENTION` 天数的旧日志。
2.  **容量限制**：如果单日记录超过 1000 条，会自动删除最早的记录，确保数据库文件 (`bot_data.db`) 不会无限膨胀。

## 🛠️ 常见问题

**Q: 为什么机器人不回复消息？**
A: 请检查 `WEBHOOK_URL` 是否正确，且必须是 `https`。同时确保 `TOKEN` 填写无误。

**Q: 为什么新成员进群没有验证？**
A: 请确保机器人已经被设置为**群管理员**。

**Q: 如何修改违禁词？**
A: 不需要修改代码，直接在部署平台修改环境变量 `SPAM_KEYWORDS`，然后重启容器即可。
